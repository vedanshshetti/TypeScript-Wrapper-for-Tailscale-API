# TypeScript-Wrapper-for-Tailscale-API
A TypeScript-based wrapper for the Tailscale API (see https://tailscale.com/api).

> NOTE: This SDK is community made software, it is not created by, endorsed by, or affiliated with Tailscale Inc. in any way.

## Installation
`npm install @vedanshshetti/tailscale-api-wrapper`
OR
`pnpm install @vedanshshetti/tailscale-api-wrapper`
